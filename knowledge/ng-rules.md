# 禁止事項(ng-rules)  版: v1 / 2026-10-15

## 規約・権利
- 他サイトの本文、当選率、個別の一覧を保存・転載しない。
- 店舗フォームへの自動応募は作らない。
- 取得頻度は1日2回以内。robots.txt と利用規約を確認してから自動化する。
- 規約が確認できていないサイトは、自動取得の対象にしない。

## 誤情報
- 推測で日付、条件、支払い方法を埋めない。
- 画像から読めない箇所は null にし、確認待ちにする。
- 締切不明のものを公開しない。
- 第三者の情報だけで「確認済み」と書かない。

## 表現
- 「必ず当たる」「絶対」「今すぐ」などの断定や煽りを使わない。
- 当選を保証する表現、当選率の推測を書かない。
- 説明文は、照合済みの項目からだけ作る。他社の文章の言い換えは使わない。

## 凍結・AI臭の防止
- 同じ文の繰り返し、不自然に長い定型文を避ける。
- 大量の自動投稿や、短時間の連続アクセスをしない。

## アフィリエイト(v2 / 2026-10-15)
- 抽選対象の商品、オリパ、ガチャ、転売目的の商品には、広告を貼らない。
- 広告の文言で、当選や入手の保証、「今だけ」「残りわずか」などの煽りを使わない。
- PR表示のない広告リンクを置かない。広告リンクには rel="sponsored" を付ける。
- 広告の掲載位置で、抽選の並び順や締切の見せ方を変えない。
- 提携の規約で禁止されている表示(価格の固定表示など)は、規約どおりに従う。規約を確認するまで掲載しない。
- 広告の商品情報を、公式の商品ページ以外の推測で書かない。
