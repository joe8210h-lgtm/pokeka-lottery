# 商品の単位(unit・packs・kind)を入れるための確認表

作成: 2026-11-03。画面の価格表示(例: 「6,000円（税込）/BOX」「1人1BOXまで（30P入り・200円/P）」)を出すには、products.json の商品ごとに、次の3項目(任意)が必要。
入れなくても動く(価格だけを表示する)。入れるかどうか、値は運営側が公式の商品ページで確認して決める。

## 項目
| 項目 | 値 | 意味 |
|---|---|---|
| unit | BOX / セット / パック | 販売の単位。画面の「/BOX」「1人1BOXまで」に出る |
| packs | 1以上の整数 | 1つ(unit)あたりのパック数。unit が BOX のときだけ。「1パックあたり◯円」の計算に使う |
| kind | box / set / pack | 画像が無いときの代わりの絵の種類 |

validate.py が、値の種類と組み合わせを検査する(unit が BOX 以外のときの packs など)。

## 入れた値(2026-11-03、運営の判断)
運営の方針「拡張パックは1BOX=30P、周年記念の30thは20P」に基づいて入れた。BOX入数は公式ページに記載がなく、公式での確認はできていない。確認できた公式の値は、1パック価格(ハドウシーカー200円、30th CELEBRATION 360円)のみ。セット商品は packs なし。イレギュラーは抽選告知で見つけ次第、報告して直す。

## 入れ方
1. 公式の商品ページ(products.json の img_source にあるもの)で、入数を確認する。
2. products.json の該当商品に、unit・packs・kind を足す。
3. データを変更すると、GitHub Actions が scripts/validate.py で自動検証する。

## 注意
- p-3 の商品名は「ハドウシーカー」で、「拡張パック」が付いていない。表示名を変える場合は products.json の name を直す(aliases と重複しないこと)。
- 出どころが他サイトの値は、公式で確認できるまで入れない(CLAUDE.md 10番・15番)。
