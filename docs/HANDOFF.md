## 4. 仕組み(現在の構成)
### 4-1. 取り込みの流れ(実装済み・一部テスト中)
1. スプレッドシート「ポケカ取込」の1行に入力(A〜I列。J列=確認済みのチェックボックス、K列=状態)。
2. Apps Script(`apps_script/sheet_sync.gs`)が10分ごとに動き、GitHubにIssueを作る(ラベル x-intake、review-needed)。K列に「作成済み #番号」と書く。
3. Actions(`x-intake-parse`)が、`scripts/parse_intake.py` で本文を項目に分け、確認用の結果をIssueにコメントする。注意(商品名の空欄、支払いの不明)も出す。
4. 人が、店舗の公式情報と照らして確認し、J列にチェックを入れる。Apps Scriptが Issue を「確認済み」にし、`approved` ラベルを付ける。
5. Actions(`x-intake-approve`)が、`scripts/apply_intake.py` で `data/lotteries.json` に追加するPRを作る。条件: 確認状況のチェックあり、受付終了あり、商品名あり、店舗名が `shops.yaml` と一致、IDの重複なし。満たさないときは、理由をIssueに書いて止まる。
6. **人がPRをマージしたときだけ公開される。**

### 4-2. Apps Scriptの設定(確認済み)
- タイムゾーンは日本標準時(東京)。`installTrigger` を実行して、10分ごとのトリガーを設定済み(実行ログに「実行完了」)。
- GitHubのトークンは、Apps Scriptの「スクリプト プロパティ」の `GITHUB_TOKEN` に保管(プログラムの中には書かない)。リポジトリ `pokeka-lottery` だけに限定した fine-grained トークンで、Contents、Issues、Pull requests を Read and write。**作成から90日で期限が切れる(2026-11-01作成なら、2027-01-30頃)ので、更新が必要。**
- Googleの「このアプリは確認されていません」の警告は、自分のスクリプトを自分のアカウントで動かすときの通常の表示。

### 4-3. ファイル構成

## 6. 実際に起きた問題と対策(learn)
- **ラベルが付かない**: ラベルがGitHubに存在しないと、Issueの作成時に付かない。`x-intake`、`review-needed`、`approved` を手で作成済み。
- **K列を空にすると、新しいIssueが作られる**: 状態(K列)が空の行は「新規」と見なされる。エラー表示を消すときに、Issue #4が重複して作られた。**K列は、新規の行以外では消さない。**
- **トークンの権限**: 読み取り専用だと、ラベル付けとPR作成が `403` で失敗する。
- **GitHubのWebで隠しファイルをアップロードすると名前が変わる**(`.gitignore` が `download` に)。隠しファイルやフォルダは「Create new file」で名前を入力して作る。
- **ブラウザからのアップロードは、フォルダ構造を保たない**。フォルダの中に入ってから入れるか、GitHub Desktopで一括して送る。
- **PRの検証が赤でも、マージは止まらない**(ブランチ保護は未設定)。赤のPRは、原因を調べるまでマージしない。
- **GitHub Desktopの送信**: 要約(Summary)の欄に入力しないと、コミットのボタンが押せない。
- **Cloudflare(Workers)は、`.git` を含めてアップロードする**。`.assetsignore` で除外し、`/.git/config` が表示されないことを確認する。
- **端末の出力を日本語の途中で切ると文字化けする**。

## 7. ポケカ抽選の専門知識(確認できた事実)
- **イオンスタイルオンライン(規約の画像で確認)**: 決済は、注文者と同一名義の「イオンカード」のみ(デビット・プリペイド不可)。1商品につき1人(1世帯・同一住所)1回。複数アカウント・メール・電話番号での重複応募は全て無効。当選はメールで通知し、当落の問い合わせは不可。当選の権利は譲渡不可。注文後のキャンセル・返品・交換は不可。届け先の不備は事前通告なくキャンセル。
- **ビックカメラ**: 条件は店舗・抽選ごとに変わる。池袋本店の7月の抽選(店頭ポスターで確認): 指定レジで受付。ポイントカード、Suica等の提携カード、公式アプリが対象(コジマ・ソフマップのカードは対象外)。カードは告知前の基準日までに発行・登録済みであること。指定期間(約2年間)の購入履歴と、本人名義のマイナンバーカードが必要。複数店舗で同時実施されても応募は1店舗のみ。レシートが控えと当選引換券を兼ね、再発行不可。発表は店頭掲示と店舗の公式X。購入期間は発表の翌日から3日間。シュリンクと外箱は回収。受付を途中で打ち切る場合あり。10月の4店舗の抽選は、第三者の投稿のみ(未検証)。
- **ヨドバシ(ユーザー提供の画像。公式で要確認)**: 会員(入会無料)と、過去2年の購入履歴。基準日は抽選ごとに異なる。受付は11:00〜翌10:59、発表は翌日18:00、注文期限は翌々日23:59というパターンが、2023〜2025年の複数回で続いている。応募は専用サイトで、ログインが必要。
- **ヤマダデンキ**: 公式通販サイト(ヤマダウェブコム)のページに、店舗のXへのリンクはない。2026年7月に「ヤマダデンキを騙った偽投稿に注意」の告知が出ている。**名前だけでXのアカウントを登録しない。**
- **その他のチェーン**: 競合の記載を要約した「ヒント」のみ(data/chains.yaml の hint。すべて未検証)。公式で確認するまで、画面の条件には使わない。
